# Code Migration Agent

Stage 1 provides repository scaffolding for a Gin-to-Hertz migration agent.

## Requirements

- Python 3.13.14
- Go

## Python CLI

```shell
python -m agent --help
```

After installing the project, the CLI is also available as:

```shell
code-migration-agent --help
```

## Go analyzer CLI

```shell
cd go-analyzer
go run ./cmd/analyzer --help
```
